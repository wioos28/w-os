# Plan: Tách Hệ điều hành (WOSCore) + Framework App (v2.3.0)

## Goal
Tách hệ điều hành ra thành module độc lập `WOSCore`. Phần khung app (UI, views, apps) ở lại `WOSApp` và import `WOSCore`.

- **WOSCore** = OS riêng, không SwiftUI, có thể dùng lại cho project khác
- **WOSApp** = Framework UI chỉ có views, themes, apps — dùng WOSCore

---

## Step-by-step Implementation

### Step 1: Create WOSCore module structure

Create directory: `Sources/WOSCore/`

#### 1.1 `Sources/WOSCore/Utils/WOSColor.swift`
- Pure Foundation hex color parser
- Returns `(r: Double, g: Double, b: Double)` tuple
- File: NEW

#### 1.2 `Sources/WOSCore/Utils/WOSConstants.swift`
- Version string, repo URLs, UserDefaults keys
- Extract from `OSDownloadService` and `AppCatalogService`
- File: NEW

#### 1.3 `Sources/WOSCore/Models/IconRef.swift`
- Simple struct: `struct IconRef: Hashable, Codable { var symbol: String }`
- NO `view()` method, NO `import SwiftUI`
- File: NEW

#### 1.4 `Sources/WOSCore/Models/SystemApp.swift`
- `struct SystemApp: Identifiable, Hashable { let id, title: String; let iconSymbol: String; let colorHex: String }`
- File: NEW

#### 1.5 `Sources/WOSCore/Models/RealApp.swift`
- Already uses `colorHex: String` and `iconSymbol: String`
- Remove `var color: Color` and `var icon: IconRef` (resolve in UI layer)
- File: NEW

#### 1.6 `Sources/WOSCore/Data/SystemAppsData.swift`
- Use hex strings instead of `Color(hex:)`
- File: NEW

#### 1.7 `Sources/WOSCore/Data/RealAppsData.swift`
- Already uses hex strings, copy as-is
- File: NEW

#### 1.8 `Sources/WOSCore/ViewModels/SystemState.swift`
- Core state: screen routing, windows, user profile, persistence
- REMOVE overlay booleans → UI layer
- Keep: screen, windows, frontWindowId, installedApps, profile, wallpaper, bootDriveMode
- Keep: UserDefaults, boot(), window management, install/uninstall
- File: NEW

#### 1.9 `Sources/WOSCore/Services/AppCatalogService.swift`
- Change `SystemApp`/`IconRef` references to hex/string
- File: NEW

#### 1.10-1.12 `BootDriveService`, `CloudSyncService`, `OSDownloadService`
- Copy as-is (already self-contained)
- Files: NEW

---

### Step 2: Create WOSApp module (refactored)

#### 2.1 `Sources/WOSApp/Extensions/IconRef+View.swift`
- Extension on `IconRef` from WOSCore: `func view(size:color:) -> some View`
- File: NEW

#### 2.2 `Sources/WOSApp/Extensions/Color+WOS.swift`
- `Color(hex:)` init + all semantic colors + View extensions
- File: RENAME from Theme/Colors.swift

#### 2.3 `Sources/WOSApp/Extensions/SystemApp+WOS.swift`
- `var color: Color { Color(hex: colorHex) }`
- `var icon: IconRef { IconRef(symbol: iconSymbol) }`
- File: NEW

#### 2.4 `Sources/WOSApp/Extensions/RealApp+WOS.swift`
- Same pattern as SystemApp
- File: NEW

#### 2.5 `Sources/WOSApp/ViewModels/WOSShellState.swift`
- Wraps `SystemState` from WOSCore
- ADD: showControlCenter, showNotifications, showSearch, showMultitask
- This is the `@EnvironmentObject` for all views
- File: NEW

#### 2.6 `Sources/WOSApp/Services/LinkingService.swift`
- Keep as-is (uses UIApplication)
- File: MOVE

#### 2.7 Move all Views and Apps
- `Sources/wOS/Views/*` → `Sources/WOSApp/Views/`
- `Sources/wOS/Apps/*` → `Sources/WOSApp/Apps/`
- `Sources/wOS/Theme/Wallpaper.swift` → `Sources/WOSApp/Theme/Wallpaper.swift`
- `Sources/wOS/wOSApp.swift` → `Sources/WOSApp/wOSApp.swift`

---
